## 1. 本地访问与账号

- 官方运营后台：`http://localhost:3001/#/admin-login`
- 业务 API：`http://localhost:4000/api/v1`

- 用户端：手机号 `13800138888`，验证码 `123456`
- 运营后台：`operator / 123456`

用户端和运营后台使用独立登录状态。登录回跳遵循来源页面：从首页登录返回首页；从受保护页面登录返回原页面。运营后台、报告进度和报告详情均有直接地址访问保护。

## 2. Web 用户端

已实现首页、全球/国内数据库切换、企业搜索、候选主体确认、主体详情、模块原地选择、组合优惠、登录、收银台、支付方式示例、发票资料、报告任务进度、在线报告、报告 PDF、AI 报告问答和用户中心。

首页使用正式 SQJ Logo、统一字号与绿黑橙辅助色；搜索框已去掉 Command + K，窄屏无横向溢出。模块选择不会刷新或跳回页面顶部。中国企业报告同时显示英文名称和中文名称，全球企业以英文名称为主。

用户中心包含报告与订单、余额充值示例、API 账户、登录方式、普通发票/专用发票抬头、合并开票、电子发票接收邮箱和退出登录。

## 3. 热门资讯

资讯为免费内容，不显示价格。已实现大宗数据、投资日报、金融市场、上市企业和其他分类，每页 10 条内容、文章详情、来源链接和原创深度解读。来源示例覆盖生意社、金十数据、投中网、华尔街见闻、同花顺和雪球。

运营流程为：资讯 Agent 定时采集候选稿，进入人工审核队列；运营人员查看标题、摘要、正文和来源后通过、拒绝、删除或重新采集；审核通过后发布到用户端。

## 4. 数据 API 平台

API 市场采用左侧 8 类目录、右侧 33 个 API 列表。市场负责发现、比较、价格和开通；开发文档负责具体接口的概览、请求参数、返回字段、调用示例与计费说明；开发者控制台负责 API Key、余额、用量和调用记录。

API Key、API 文档、CLI、MCP、调用日志和人民币余额均已接入页面闭环。鉴权统一为 `X-API-Key`；只有成功且可计费的请求从人民币余额扣款。API 单价为小额按次调用价，与报告模块价格分开。

公开可查看 API 市场、分类、接口概览和接入说明；API Key、余额、用量和调用记录登录后才能查看。详情页左侧目录随右侧滚动高亮，窄屏下参数表和代码示例不会撑破页面。

## 5. 报告与 PDF

Northstar Components Inc. 报告包含封面、执行摘要、M01–M10 和数据责任说明。页面正文共 12 个章节，无代码块。未购买和无覆盖模块只显示状态与能力边界，不生成推测内容；报告不允许生成公开外链。

示例 PDF 已嵌入中文字体，A4 共 13 页，包含完整目录内容、已购模块事实、未购模块边界、来源与数据责任说明。Northstar 报告页的“打印 / 保存 PDF”直接下载已验收文件。

## 6. 官方运营后台

运营后台已实现独立登录、运营总览、今日待办、企业数据源、覆盖与质量、资讯审核与发布、资讯来源、报告产品、报告任务、API 产品与客户、调用与计费、客户使用情况、客户详情、订单与退款、订单详情、余额与充值、发票管理、发票详情、AI 与 Agent、操作与审计日志、日志详情和退出登录。

各业务页使用对应的页面结构而非通用空模板：资讯页为采集稿审核队列；数据源页为供应商、路由和字段质量；报告产品页可配置原价、折扣和折后价；API 页配置商品、单价、客户和调用；交易页展示订单、退款、余额和发票；审计页可筛选日常操作、重要变更、资金与内容记录并查看依据和关联单据。

## 7. 测试数据与适配层

Mock 上游包含 100 家合成企业，每家 10 个完整业务模块，共 1000 份模块数据；另保留 Northstar、OpenAI 等固定演示主体。市场覆盖中国大陆、美国、中国香港、新加坡、英国、德国、日本、韩国、荷兰和法国。API 商品为 8 类 33 个。

支付和开票当前明确标注为 Mock / 示例，真实企业数据、支付、开票、资讯采集和 LLM 均通过 Provider Adapter 替换。正式接口到位后无需改变页面结构和对客契约。
