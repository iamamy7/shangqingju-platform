# 商情局正式开发工程

本目录是依据商情局 PRD、总体技术方案、交接手册、33 个 API 接口文档和最终交互原型完成的正式开发工程。用户端、开发者平台和官方运营后台均已按原型迁移，并保留后续替换真实上游接口的适配层。

## 工程组成

- `apps/web`：Web 用户端与移动端适配，Nuxt 3。
- `apps/admin`：官方运营后台，Nuxt 3，使用独立登录会话。
- `services/api`：统一业务服务，NestJS。
- `packages/contracts`：前后端共享的返回结构、鉴权、计费与 Provider 契约。

## 已确定的工程规则

1. 用户端和运营后台分别登录，不共享会话。
2. API 对客鉴权统一使用请求头 `X-API-Key`。
3. API 以人民币余额结算，仅成功且可计费的调用扣款。
4. 企业数据、支付和开票全部通过 Provider Adapter 接入；首期可使用 Mock，后续替换实现，不修改业务页面。
5. 报告进度与详情同时校验登录状态、订单支付状态和资源所有权。
6. 报告不生成公开外链。


## 已实现范围

- Nuxt Web、Nuxt 运营后台和 NestJS API 可独立运行并完成生产构建。
- 100 家完整合成企业加 12 个固定演示主体，共 112 个可检索主体。
- `Northstar Components` 可返回多个候选，中文企业名称可检索。
- 8 类 33 个 API 商品目录和单接口详情，按原型的小额人民币价格展示。
- 用户手机号登录与运营后台登录使用不同角色会话。
- 企业搜索、单企业基础信息与 M01–M10 模块数据接口。
- 企业确认、模块原地勾选、组合优惠、登录回跳、订单、余额支付、报告进度和受保护报告详情闭环。
- Northstar Components 的股权、管理层、财务、司法、制裁、融资及知识产权等完整演示数据。
- 用户个人中心：报告订单、人民币余额、充值入口、专票资料、开票说明、登录账号与退出登录。
- 公开免费的热门资讯列表、分类和原创深度文章详情。
- 独立的官方运营后台登录，以及数据、内容、报告、API、客户交易和审计菜单；资讯支持逐篇审核。
- 开发期订单与余额持久化；生产环境将使用 PostgreSQL，不改变现有接口契约。
- 报告下载使用嵌入中文字体的 A4 PDF，覆盖封面、执行摘要、M01–M10 和数据责任说明，不再出现中文乱码、章节遗漏或代码内容。
- 自动测试覆盖企业数据、资讯、登录、API Key、余额计费、支付示例、开票示例、报告任务、AI 问答和两个前端服务；正式生产构建已通过。
